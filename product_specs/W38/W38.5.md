## Objective

Fix the logo so it stops rendering as a white box on dark backgrounds, ship a
proper favicon set, and make the site look right when someone shares the link —
which, given TSA's traffic comes from an Instagram bio link, is the first thing
most visitors will ever see of it.

## Background

**The logo is a JPEG.** `public/logo.jpg` is TSA's circular emblem — and JPEG has
no alpha channel, so it carries an opaque rectangular background. It's placed in
three spots, two of them dark:

| Location | Background | Result |
| --- | --- | --- |
| `aero-hero-2.tsx`, top-left over the hero photo | dark photo + gradient | opaque box over the image |
| `Footer.tsx` | `#241D4F` navy | white/light box on navy |
| `HomePage.tsx` → `StaggeredMenu` `logoUrl` | menu panel | depends on panel color |

A circular logo in a visible square is the most obvious "unfinished" tell a
website can have, and it's on the hero — the first thing anyone sees.

**The favicon is the same JPEG.** `index.html` has
`<link rel="icon" type="image/jpeg" href="/logo.jpg" />` — a full photo-sized
JPEG serving as a 16px browser-tab icon. It renders as an unreadable smudge and
downloads far more bytes than a favicon should.

The leading-slash path is *not* a bug, though it looks like one: Vite rewrites
root-relative asset URLs in `index.html` at build time, so it ships as
`/tsa-website/logo.jpg` correctly. (Verified — check `dist/index.html` yourself
and you'll see it.) This is worth knowing because the same leading slash **would**
break inside a `.tsx` file, where Vite does not rewrite it. `index.html` is
special.

**There are no Open Graph tags.** Paste the URL into Instagram, Discord, iMessage
or Slack and you get a bare link with no image, no title card, nothing. For a
club whose main channel is Instagram, this is the highest-visibility bug on this
list.

Also: `thai.jpg` (390KB) sits in the **repo root**, not in `public/`, and nothing
references it. `public/thai.jpeg` is the one the hero actually uses. Worth
checking whether the root one is a stray.

## Specification

1. **Produce a transparent-background logo.** Get the original from the club if
   you can — ask before you spend time editing. Their graphic designers will have
   a PNG or vector master, and one Discord message beats an hour in an image
   editor.

   Failing that, remove the background from `logo.jpg` yourself. GIMP, Photopea
   (free, browser-based), or `remove.bg` all work. Export as PNG with alpha at
   roughly 512×512.

   **Check the edges.** JPEG compression leaves halo artifacts around high-contrast
   edges, and a naive background removal will leave a grey fringe that's invisible
   on white and glaringly obvious on navy. Zoom to 400% and inspect. Test the
   result on the actual footer navy before calling it done.

2. **Swap the three usages** to the transparent PNG. Keep using
   `import.meta.env.BASE_URL` — all three already do, correctly.

3. **Build a favicon set** and wire it up in `index.html`:
   - `favicon.svg` — vector, scales perfectly, preferred by modern browsers
   - `favicon-32.png` — fallback
   - `apple-touch-icon.png` at 180×180 — iOS home screen

   At 16px the full emblem will be an unreadable smudge. Favicons need a
   simplified mark — often just the "TSA" letterform, or the central motif alone.
   Look at how other clubs solve this. Zoom your browser tab to check.

4. **Verify the built icon paths.** Root-relative paths in `index.html` are
   rewritten by Vite, so `href="/favicon.svg"` is fine there. Run `npm run build`
   and confirm in `dist/index.html` that each icon resolves under
   `/tsa-website/` — don't assume it. If you prefer to be explicit,
   `href="%BASE_URL%favicon.svg"` is substituted at build time and makes the
   intent obvious to the next reader. See the README's "Referencing assets"
   section for why `.tsx` files are different.

5. **Add Open Graph and Twitter Card meta tags.** Minimum set:

   ```
   og:title           Thai Student Association at UMD
   og:description     (the existing meta description is fine)
   og:image           absolute URL to og-image.jpg
   og:url             absolute site URL
   og:type            website
   twitter:card       summary_large_image
   ```

   **`og:image` must be an absolute URL** — `https://campuscoderscrew.github.io/tsa-website/og-image.jpg`.
   Relative paths do not work; crawlers fetch the image from their own servers
   with no page context. This is the single most common way OG tags silently fail.

6. **Create the OG image** at 1200×630. Use a strong photo from `public/` with
   the logo and the club name over it. Keep text away from the edges — different
   platforms crop differently. Keep it under ~300KB.

7. **Check whether root `thai.jpg` is unused.** Grep the repo for `thai.jpg`
   (note: `public/thai.jpeg` is a *different* file with a different extension, and
   it *is* used — don't delete that one). If the root file has no references,
   delete it and note the saving in the PR. If you're unsure, leave it and say so.

8. **Set `<html lang="en">`** — already correct in this file. Just confirm it
   survived your edits.

## Hints

- **Ask the club for the original asset first.** Seriously. Five minutes of
  asking beats an hour of tracing.
- Photopea (photopea.com) is a free browser Photoshop and handles background
  removal fine. No install.
- On a circular logo, a 1px feathered edge avoids both a jagged cutout and a
  halo. Too much feather on navy reads as a glow.
- OG tags can't be tested locally — crawlers need a public URL. Deploy to a
  branch preview, or merge and test on the live Pages URL. opengraph.xyz and
  Discord (paste a link in any channel) are the fastest checks.
- OG images get cached hard by platforms. If you fix an image and the old one
  still shows, that's a cache, not your code. Facebook's Sharing Debugger can
  force a refresh.
- SVG favicons can embed a `prefers-color-scheme` media query to invert on dark
  browser themes. Nice touch if you have time; not required.
- This spec is a string of small, independent wins. If you run out of time, land
  what you have — each piece is separately valuable.
